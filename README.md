# 光体·星际档案馆

根据提供的 PRD 与光体金色几何 logo 制作的可运行网站。直接用现代浏览器打开 `index.html`，无需安装依赖。

## 已实现

- 10 项独立主导航、沉浸式首页、可暂停的精选轮播、7 个主题馆、专题探索与文献资源组成的 9 个内容栏目及 25 条专题阅读路径。
- 234 份带原始出处的公开资料摘要（127 份首批 + 107 份 2026-09 深度扩充），详情区分官方资料、科学研究、理论假说、争议材料和文化叙述；每条记录包含至少三段可读正文，关键记录另有分章深读。
- 9 大版块的全部细分分类均已填充深度档案：史前超文明（姆大陆/雷姆利亚/苏美尔王表/摩艾/帕伦克/德里铁柱/普马彭谷/昌克罗/新仙女木/青铜崩溃/都灵王表/皮里·雷斯 + Digital Giza/ADS/绝版书目素材库）、地外文明（盖亚/新视野/FAST/FRB/METI/海盗号/EHT/系外行星档案/TRAPPIST-1/韦伯深场/巴罗尺度/接触论思想史/海洋世界/金星磷化氢/arXiv/年评）、外星种族（蜥蜴人/昴宿/天狼星多贡/猎户座/仙女座 + 索科洛/阿拉加什/安德烈亚森/医学检视）、UAP（纽伦堡1561/幽灵火箭/华盛顿1952/JAL1628/比利时波/奥黑尔/罗斯威尔 + FBI/GEIPAN/康登报告 + 光球/三角/雪茄/雷达分离/跨介质/编队分类 + 官方影像索引）、麦田怪圈（朱利亚集/奇尔博尔顿/Crabwood/π 图案 + 阿雷西博镜像分析/几何门槛/天文对应检视 + BLT 争议 + Pringle 航拍与影像索引）、北纬三十度（乌尔/印度河/奇琴伊察坐标示范 + 死亡谷/珠峰/撒哈拉之眼 + 第19中队/老爷庙/神农架科考 + 三星堆素材/地磁数据工具/书单）、远古符号（北美岩画/奇普/敦煌星图/拉斯科假说/汉墓星象图 + 卍形/螺旋比较 + 拓片库/专著书架）、文献资源（加拿大/NSA 解密 + DOAJ/Crossref + Open Library/HathiTrust + USGS/中国考古入口 + Prelinger/NASA 影像库）。
- 新增“远古符号档案”与文物元数据；“地外文明探索”收录真实深空任务、SETI 和观测资料；“北纬三十度”保留地理坐标与实际来源。

- 档案收藏、浏览足迹与摘要导出记录，使用当前浏览器本地存储。
- 图片全幅预览、来源链接、带原始出处的 TXT 摘要导出、补充线索本地导出。

- 桌面、平板及手机响应式布局、键盘操作、减少动画偏好支持。

## 文件

- `index.html`：页面入口与公共弹窗。
- `styles.css`：视觉与响应式样式。
- `app.js`：路由、检索、收藏、资料阅读及交互。
- `data.js`：首批档案正文与出处。
- `supplement.js`、`content_core_fragment.js`、`content-secondary.js`、`content-coverage.js`：按栏目拆分的深度补充档案。
- `content-expansion-a.js` 至 `content-expansion-d.js`：2026-09 九大版块深度扩充批次（107 份档案 + 12 条专题路径，专题路径由 `ARCHIVE_TOPICS_EXTRA` 提供）。
- `content-merge.js`：按唯一 ID 合并各批次数据，避免重复入馆。
- `assets/`：本地 logo、图片和视频。
- `vendor/`：本地 Lucide 图标库及许可。

所有页面素材均在本地。打开原始出处需要网络。把完整目录放在静态网站托管服务即可运行，hash 路由无需服务端重写。

## 当前范围

这是可离线运行的前端版本，未接入手机号验证码、账号系统、跨设备云端同步、内容管理后台、在线投稿审核与站内原文镜像。收藏等数据只属于当前浏览器及其存储范围；迁移到其他目录、浏览器或域名时可能不会共享。浏览器禁止本地存储时，应用保留当前页面会话内的数据并提示。

“导出档案摘要”提供本站中文摘要与出处索引，不表示已下载完整研究报告、第三方图片或整站资源。补充线索仅导出本地文本，不向外部发送。首批资料没有声称覆盖全部事件或实时更新。

## 来源与许可

每份档案在详情页列出原始机构与来源日期。页脚“资料与版权”提供全部图像的作者、出处与许可链接。

金字塔图像及缩放版采用 CC BY-SA 4.0，哥贝克力图像及缩放版采用 CC BY-SA 3.0，巨石阵和 VLA 图像采用 CC BY 2.0，M31 图像采用 CC BY 4.0。其他图像按各自来源页的许可使用。GOFAST 视频来源为公开的美国政府影像，此处为压缩静音预览。品牌 logo 由用户提供。
